# WoW Forever · Optimizador de Profesiones (1–150)

Herramienta interactiva web y móvil (PWA) para calcular la ruta óptima marginal de profesiones (Tailoring, Enchanting, Leatherworking, Blacksmithing, Alchemy, Engineering) hasta habilidad 150, consultar rentabilidad en subasta y ver perfiles in-game en **WoW Forever**.

- Precios en vivo: [Forever AH](https://forever-ah.com)
- Datos de recetas y tooltips: [ForeverDB](https://foreverdb.net)
