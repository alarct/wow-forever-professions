# WoW Forever · Optimizador de Profesiones (1–300)

Herramienta interactiva web y móvil (PWA) para calcular la ruta óptima marginal de profesiones (Tailoring, Enchanting, Leatherworking, Blacksmithing, Alchemy, Engineering) de habilidad **1 a 300**, filtrar rentabilidad por rangos de habilidad, ver perfiles in-game y actualizar precios en vivo de Forever AH.

- Web en vivo: https://alarct.github.io/wow-forever-professions/
- Precios en vivo: [Forever AH](https://forever-ah.com)
- Datos y tooltips: [ForeverDB](https://foreverdb.net)
