# WoW Forever · Optimizador de Profesiones (1–300)

Herramienta interactiva web y móvil (PWA) para calcular la ruta óptima marginal de profesiones (Tailoring, Enchanting, Leatherworking, Blacksmithing, Alchemy, Engineering, Cooking y First Aid) de habilidad **1 a 300**, detectar crafteos con **Margen seguro (100% días históricos > 0)** y sólidos sin trampas de picos (Espejismos, Mats en oferta, Escasez y Valoración conservadora), analizar bandas normales P25–P75, ver perfiles in-game y actualizar precios en vivo de Forever AH.

- Web en vivo: https://alarct.github.io/wow-forever-professions/
- Precios en vivo: [Forever AH](https://forever-ah.com)
- Datos y tooltips: [ForeverDB](https://foreverdb.net)
